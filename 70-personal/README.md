# 70-personal — личный лайф-админ

Зона для **структурированных личных данных**: не заметок «вообще», а повторяющихся решений, которые удобно считать, сравнивать по месяцам и проверять отчётом.

Каждая тема живёт **подсистемой** — папкой со своим набором файлов:

```
70-personal/<подсистема>/
├── profile.md            профиль предпочтений и приоритетов (меняется редко)
├── providers/            специфика по каждому провайдеру (банк, сервис, тариф)
│   └── <провайдер>.md
├── history/              машиночитаемая история по периодам
│   └── YYYY-MM.md
└── report-YYYY-MM.md     производный отчёт по периоду
```

Подсистемой может быть что угодно с повторяющимся выбором: кэшбек банков, подписки и тарифы, страховки, ЖКХ, медицина. Паттерн переносится, меняются только ключи.

## Почему так, а не просто заметками

1. **Данные во frontmatter, тело — читаемый вид.** Периодический файл — это машиночитаемая модель (объёмы, лимиты, выбор по провайдерам) плюс таблица для человека. Это даёт сравнение месяцев и проверяемые отчёты, чего обычная заметка не даёт.
2. **Профиль отделён от периода.** Приоритеты владельца меняются редко, выбор по месяцам — часто. Разделение избавляет от переписывания одних и тех же предпочтений каждый период.
3. **Отчёт — производное.** Он не содержит новых фактов, только выводы по уже записанному входу.
4. **Провенанс — материалы владельца.** Источник наполнения: скриншоты, выписки, диктовка. Скриншоты — личный материал, поэтому обрабатываются **локально** (см. скилл `wiki-ocr`, ступень 1: локальный OCR, без отправки в облако).
5. **Допущения помечаются.** «ПРЕДПОЛОЖИТЕЛЬНО — уточнить» прямо в тексте: неизвестное не подаётся как известное.

## Шаблоны

Поля каждого типа — в `90-meta/templates/`:

- `lifeadmin-profile.md` — профиль предпочтений
- `lifeadmin-provider.md` — провайдер
- `lifeadmin-month.md` — файл периода (машиночитаемая модель)
- `lifeadmin-report.md` — отчёт

## Пример

`example/` — заполненный скелет подсистемы с вымышленными провайдерами и нейтральными категориями. Показывает форму, а не содержание: **прочитал — можно удалить**, на реальные данные он не влияет.
