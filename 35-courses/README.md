# 35-courses — изучаемые курсы

Зона учебных материалов. Отдельная зона, а не раздел `10-wiki`: у курса свой жизненный цикл (карточка, модули, инсайты, промоушен зрелого в знания), а `10-wiki` держит уже переиспользуемое знание без учебного контекста. Смешивать — потерять обе модели: конспект лекции начинает притворяться проверенным знанием.

Маркер зоны — `.llm-rw`.

## Устройство

```
35-courses/
  README.md                 — контракт зоны (этот файл)
  hub.md                    — хаб: курсы по статусу, очередь инсайтов (генерируется)
  <slug>/                   — папка курса, slug = kebab-case
    course.md               — карточка курса
    m01-<тема>.md           — конспект модуля
    insights/NN-<слаг>.md   — инсайт
```

Слаг курса = имя папки. На него ссылаются поле `course` на модулях и инсайтах, `index.md` и хаб. Нумерация модулей (`m01`, `m02`) задаёт порядок чтения и сортировку; буква после номера — для модулей, добавленных задним числом (`m03a`).

## Три типа страниц

Источник истины по полям — шаблоны `90-meta/templates/course.md`, `course-module.md`, `insight.md`. Общие поля (`name`, `type`, `created`, `updated`, `tags`) — по контракту `AGENTS.md`.

### Карточка курса — `type: course`

| Поле | Смысл |
|---|---|
| `platform` | где проходит: площадка, школа, канал |
| `author` | преподаватель или школа |
| `status` | `planned` · `active` · `paused` · `done` · `dropped` |
| `started` | дата старта; обязательна для `active`/`paused`/`done`, не нужна для `planned` |
| `finished` | дата завершения, заполняется при `done` |
| `sources` | страница курса, плейлист, `[[диктовка YYYY-MM-DD]]` — непустой |

Тело: чему курс обещает научить (2–3 строки), программа модулями-викилинками, итог после `done` — что забрал и что применено.

### Конспект модуля — `type: course-module`

| Поле | Смысл |
|---|---|
| `course` | слаг папки курса |
| `part` | номер модуля строкой: `"01"`, `"03a"` |
| `sources` | URL видео/слайдов, викилинк на транскрипт в `01-raw`, `[[диктовка YYYY-MM-DD]]` |

Тело — фиксированный скелет: `## TL;DR` (3–5 тезисов) → `## Ключевые знания` (по темам, с таймкодами) → `## Что не понял / вопросы` → `## Что попробовать`. Конспект — не пересказ лекции, а то, что понадобится через полгода.

### Инсайт — `type: insight`

| Поле | Смысл |
|---|---|
| `course` | слаг курса |
| `source` | откуда именно: модуль + таймкод (`"[[m03-<тема>]] · 12:30"`) |
| `area` | где применю: `work` · `1c` · `personal` · `study` |
| `status` | `to-apply` · `applied` · `dropped` · `promoted` |
| `promoted_to` | викилинк на страницу `10-wiki`, обязателен при `status: promoted` |
| `sources` | непустой, обычно сам модуль |

Тело — три обязательных раздела: `## Суть` (2–4 предложения своими словами) → `## Как применю` (конкретный шаг: что, где, когда) → `## Проверка` (что должно измениться и когда вернуться).

**Граница:** общее знание без личного применения — это раздел модуля, а не инсайт. Инсайт без «Как применю» не создаётся.

## Цикл

1. **Старт** — карточка, `status: active`, `started`.
2. **Модуль пройден** — страница модуля по скелету; транскрипт ложится в `01-raw/YYYY-MM-DD-<slug>-mNN-transcript.md`, слайды и PDF — только ссылками.
3. **Инсайт** — отдельная страница сразу с «Как применю», `status: to-apply`.
4. **Применение** — `applied`, либо `dropped` с причиной в теле.
5. **Промоушен** — созрело до переиспользуемого: страница в `10-wiki` (`concept`/`howto`) со ссылкой на модуль в `sources`; у инсайта `status: promoted` и `promoted_to`. Ревью-гейт: страница показывается владельцу до коммита.
6. **Финиш** — `status: done`, `finished`, итог в карточке.

Ссылки обязательны в обе стороны: модуль ↔ инсайт, промоушен ↔ `10-wiki`.

## Краевые случаи

| Случай | Решение |
|---|---|
| Курс заведён, модулей нет | Норма: карточка `planned` или `active` с пустой программой |
| Модуль просмотрен, фиксировать нечего | Страница-заглушка не создаётся; модуль появляется, когда есть что записать |
| Инсайт из вебинара или книги, без курса | `course` — ближайший курс по теме; `source` и `sources` — на первоисточник |
| Похожий инсайт уже есть | Не дублировать: дополнить существующий, поднять `updated` |
| Модуль длиннее 26 КБ | Делить по темам на `mNN-<тема>-<подтема>.md` с тем же `part` |
| Курс брошен | `status: dropped` и причина в теле; страницы остаются |

## Что зона не делает

Не трекает уроки, часы и повторения; не скачивает видео с платных платформ; не хранит бинарники — только ссылки. Прогресс курса = набор написанных модулей.

## Хаб

`35-courses/hub.md` генерируется `90-meta/scripts/gen_index.py` в том же прогоне, что и `index.md` (`make index`). Руками не правится, `make gate` ловит расхождение.
