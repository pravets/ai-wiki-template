# Словарь тем и приёмов

Контролируемый словарь для `theme` и `device` в карточках `15-precedent/bank/`. Правило то же, что для тегов: **сначала значение здесь, потом в карточке.** Свободные метки — в `tags`.

Пополнение — только по согласованию с владельцем. Две темы с пересечением смысла — повод не добавлять третью, а уточнить формулировку.

## Темы (`theme`)

| Тема | Что покрывает |
|---|---|
| `управление` | руководство, делегирование, ответственность, решения, бюрократия |
| `люди-команды` | найм, мотивация, конфликты, коммуникация в команде |
| `легаси` | старое и работающее против нового и красивого, поддержка, рефакторинг, долг |
| `ии-технологии` | автоматизация, ИИ, инструменты, хайп и его цена |
| `знания-обучение` | память, документация, обучение, экспертиза, забывание |
| `деньги-бизнес` | стоимость, ценность, продажи, рынок |
| `время-сроки` | дедлайны, планирование, оценка, спешка |
| `качество-риск` | тестирование, надёжность, аварии, цена ошибки |
| `язык-коммуникация` | формулировки, смысл слов, непонимание, двусмысленность |
| `культура-искусство` | литература, кино, музыка как рамка разговора |
| `память-родина` | история, семья, место, идентичность |
| `быт-ирония` | повседневность, абсурд, узнаваемые мелочи |

## Приёмы (`device`)

| Приём | Когда работает |
|---|---|
| `старт` | открыть доклад, задать рамку, снять напряжение зала |
| `финал` | закрыть мысль, дать формулу на выход |
| `ирония` | снизить пафос, показать знакомую проблему иначе |
| `аналогия` | объяснить сложное через бытовое или чужое |
| `контраргумент` | озвучить возражение раньше зала и разобрать его |
| `пафос` | поднять ставки, когда нужна мотивация, а не ирония |
