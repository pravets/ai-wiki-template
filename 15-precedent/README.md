# Прецедентные тексты

Зона `15-precedent/` — банк цитат, крылатых фраз, отсылок и аллюзий, которые владелец использует в докладах, презентациях, статьях и других материалах. Это **сырьё-полуфабрикат**, а не знание: оно не объясняет мир, а даёт готовую формулировку под тезис.

Маркер зоны — `.llm-rw`, но запись идёт через **ревью-гейт**: карточка показывается владельцу до коммита.

## Устройство

```
15-precedent/
  README.md        — этот контракт (ro)
  hub.md           — Dataview-хаб: весь банк, темы, приёмы, «на проверку», «использовано»
  themes.md        — контролируемый словарь тем и приёмов
  bank/            — карточки цитат (1 файл = 1 цитата)
  works/           — карточки произведений/источников (создаётся при 2+ цитатах из одного источника)
```

**Одна цитата — одна карточка.** Таблица внутри страницы произведения не годится: Dataview не видит строки таблицы, а значит пропадает выборка «по теме», «по приёму», «что ещё не проверено». Карточка произведения нужна только для общих сведений об источнике (автор, год, издание, перевод) и обратных ссылок; цитаты в неё не копируются, а линкуются.

## Контракт карточки

Источник истины полей — `90-meta/templates/precedent.md`.

| Поле | Смысл |
|---|---|
| `text` | **дословный** текст цитаты в кавычках. Правки, сокращения и адаптации — только в теле карточки |
| `kind` | `book`, `film`, `series`, `song`, `aphorism`, `anecdote`, `meme`, `proverb`, `speech` |
| `author`, `work`, `year` | автор, произведение, год первого издания/выхода (для кино — год выхода, не серии) |
| `lang` | язык оригинала |
| `theme` | темы под тезис — **только из `themes.md`** |
| `device` | приём в докладе: `старт`, `финал`, `ирония`, `аналогия`, `контраргумент`, `пафос` |
| `tags` | свободные метки (не фильтр по темам — фильтр это `theme`) |
| `attribution` | `primary` — сверено с первоисточником; `secondary` — авторитетный источник цитирует, первоисточник недоступен; `misattributed` — атрибуция ложная/легендарная (ценна отдельно); `unverified` — не проверено |
| `sources` | URL первоисточника или подтверждения — **обязательно, без исключений** |
| `used_in` | `[[slug доклада]]`, заполняется при вставке в материал |

Тело карточки: `## Контекст` (кто говорит, что происходит), `## Почему работает`, `## На слайде` (готовая формулировка), `## Проверка` (чем и как подтверждён текст).

## Железные правила зоны

1. `text` — дословно, включая пунктуацию. Сокращение в поле — порча банка: через год не понять, что было в оригинале.
2. Нет `sources` — нет карточки. Цитата «из интернета» без подтверждения — `unverified`, а не факт.
3. Ложная атрибуция не выбрасывается, а помечается `misattributed`: такие цитаты — материал для слайда-разоблачения и для собственной дисциплины.
4. Перевод: в `text` — оригинал, в `## На слайде` — перевод с указанием переводчика.
5. Новая тема — сначала в `themes.md` (согласовав с владельцем), потом в карточке.
6. Дубли ловятся по нормализованному тексту (без пунктуации и регистра) до создания карточки.
7. `used_in` обновляется в момент вставки цитаты в доклад — это защита от самоповтора между выступлениями.

## Процедура

Добавление, проверка атрибуции и подбор под слайд — скилл `skills/wiki-precedent`.
