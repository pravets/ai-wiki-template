# Wiki Lint: гигиена базы знаний

## Что проверять

1. **Сироты** — страницы без входящих wikilink: собрать граф ссылок (`[[...]]` по всем `.md`; `index.md` не считается), вывести страницы, на которые никто не ссылается.
2. **Противоречия** — утверждения разных страниц одной темы, конфликтующие между собой; собрать кандидатов с цитатами, решение за владельцем.
3. **Устаревшее** — страницы без обновления дольше N месяцев (frontmatter `updated` / git log); версии и цифры, требующие перепроверки.
4. **Пробелы** — красные ссылки `[[несуществующая страница]]`, незаполненные секции по шаблонам.
5. **Банк цитат** (`15-precedent/`): карточки без `sources`; `attribution: unverified`, висящее дольше месяца; темы и приёмы вне `themes.md`; дубли по нормализованному `text`; карточки без входящих ссылок и без `used_in`. Быстрый проход — `python3 skills/_shared/scripts/precedent_check.py <vault-root>`; входящие ссылки и `used_in` — вручную по графу.
6. **Покрытие контрактом** — сверить зоны в таблице `AGENTS.md` с `ZONE_RULES` линта: зона без правила даёт «0 нарушений» при нуле проверок и выглядит здоровой. Проверять пробой: `lint_frontmatter.py --changed <файл зоны>` на файле с заведомо пустым frontmatter — молчание значит «правил нет», а не «всё хорошо».
7. **Конфликт-файлы** синхронизации (`*.sync-conflict-*`) — перечислить, предложить разбор; удалять только после разбора владельцем.

## Порядок

0. **Машинный проход** (быстро, без чтения страниц): `make lint` — нарушения контракта с именами файлов; `make gate` — только новые сверх `90-meta/lint-baseline.json` плюс дрейф `index.md`; байты `log.md` — `make log` (отчёт, `--write` ротирует в `90-meta/log/<год>.md`). Исправил страницы — `--prune-baseline`, чтобы бэклог сокращался.
1. Прогнать проверки скриптом (Python: обход дерева + regex по wikilink; исключить `.git/`, `.obsidian/`).
2. Свести отчёт: таблица находок с путями и приоритетом.
3. Показать отчёт владельцу; правки — только после его решения (**ревью-гейт**).
4. После исправлений: обновить `index.md`, дописать `log.md`.

## Правила

- Линт не чинит молча: отчёт → согласование → правки.
- Append-only зоны (`25-interactions`, `log.md`) не ретактируются.
