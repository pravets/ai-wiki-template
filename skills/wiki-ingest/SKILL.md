# Wiki Ingest: источник → знание

Превращает сырой источник в связанные страницы вики с провенансом. Применяется в vault со структурой этого шаблона (зоны и маркеры — в `AGENTS.md`).

## Воркфлоу

1. **Приём**: источник попадает в `00-inbox` (ссылка, текст, файл).
2. **Raw**: копия текста → `01-raw`. Имя файла: `YYYY-MM-DD-<slug>.md`; шапка: источник (URL), дата получения, способ (web-clip / диктовка / ASR и т.п.). Зона неизменяемая — после записи не править.
3. **Wiki**: написать/обновить страницы в `10-wiki`:
   - новая тема → отдельная страница, slug kebab-case на английском;
   - существующая тема → обновить затронутые страницы, факты добавлять с цитатами;
   - каждый факт — со ссылкой на источник ([[wikilink]] или URL);
   - frontmatter по шаблону `90-meta/templates/wiki-concept.md` (`tags`, `sources`).
4. **Связность**: перекрёстные ссылки из родственных страниц на новую.
5. **Учёт**: обновить `index.md`; дописать `log.md` (`## [YYYY-MM-DD] ингвест | суть`, append-only).

## Ревью-гейт

- Черновик вики-страницы показывается владельцу **до коммита**; коммит — только после явного согласования.
- Крупный ингвест (много страниц): каждая страница — отдельный коммит + push, затем один финальный коммит на `index.md` + `log.md`.

## Чеклист перед коммитом

- [ ] 01-raw записан (и больше не будет правиться)
- [ ] каждый факт имеет источник
- [ ] frontmatter: `tags`, `sources` заполнены
- [ ] `index.md` обновлён, `log.md` дописан (append, не редактирование)
- [ ] бинарей нет (PDF/картинки — ссылками)

## Грабли

- ASR-транскрипты часто приходят одной строкой — нормализуй по предложениям перед записью в `01-raw`; в шапку добавь пометку об автоматическом распознавании.
- Имена продуктов и версии из транскриптов сверяй с первоисточником (репозиторий, сайт) — не переноси вслепую.
- Владелец просит только wiki-страницы без raw-копии — провенанс всё равно обязателен: `sources` в frontmatter.
- Страница про инструмент/сервис, а не тему — рассмотри секцию в существующей тематической странице вместо новой страницы.
