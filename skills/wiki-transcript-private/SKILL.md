# Wiki Transcript: приватная ветка

Для записей, которые не должны уходить третьим лицам: голосовые сообщения, личные встречи, диктовка заметок, приватные эфиры.

Шаги контура (нормализация, конспект, гейты качества, ревью-гейт) — в [`_shared/transcript-pipeline.md`](../_shared/transcript-pipeline.md). Здесь только то, чем ветка отличается.

## Когда эта ветка

- **Голосовое сообщение или диктовка от владельца — всегда приватная ветка**, без исключений: это личная запись по определению.
- Личная запись, пришедшая ссылкой, — тоже приватная.
- Источник **неоднозначный** → спросить владельца, личный это материал или публичный. Спросить некого — считать приватным.

## Инвариант приватности

1. **Провайдер — только прямой контракт или self-hosted** (свой инстанс, вендор по прямому договору). **Мультитенантные агрегаторы запрещены.**
2. Если в конфиге доступен только агрегатор — ветка **не подстраивается под него, а останавливается** с явным сообщением владельцу. Молчаливое «ну ладно, отправим как публичное» — недопустимо.
3. **Не выбирать публичную ветку ради дешевизны или скорости.** Причина выбора ветки — приватность источника, а не цена.
4. Артефакты (аудио, сырой транскрипт) не выносить в общие/публикуемые зоны; хранить по политике владельца.

## Как запускать

```bash
scripts/stt-private <файл> <выходной.txt>
```

Скрипт вендор-нейтральный (любой провайдер с OpenAI-совместимым `POST /v1/audio/transcriptions`), ссылки не принимает — только локальный файл. Без конфигурации падает с явной ошибкой, а не подменяет провайдера.

## Конфигурация

| Переменная | Значение |
|---|---|
| `STT_PRIVATE_URL` | endpoint провайдера, допущенного для персональных данных |
| `STT_PRIVATE_MODEL` | модель (обязательна: дефолтов в коде нет) |
| `STT_PRIVATE_KEY` | ключ доступа |
| `STT_LANG` | язык явно (напр. `ru`) — автоопределение на коротких клипах врёт |

Значения — в переменных окружения или в файле `.env` в корне vault'а (в `.gitignore`; другой путь — `STT_ENV_FILE`). Формат: `KEY=value`, по строке. Шаблон — `.env.example` в корне репозитория.

Владелец может не создавать файл руками: достаточно продиктовать endpoint, модель и токен — агент запишет их в `.env`. Конкретные провайдеры и цены — по выбору владельца, в шаблоне их нет.

## Чеклист

- [ ] Источник действительно личный (или неоднозначный → спросили владельца → считаем личным)
- [ ] Провайдер допущен для персональных данных, не агрегатор
- [ ] Endpoint/модель/ключ заданы (иначе скрипт упадёт — это ожидаемо, а не повод идти в публичную ветку)
- [ ] Язык передан явно
- [ ] Аудио и сырой транскрипт не попали в публикуемые зоны
- [ ] Конспект (если нужен) проходит ревью-гейт владельца
