# Wiki Transcript: публичная ветка

Для публичных материалов: видео, подкасты, стримы, рилы, лекции, вебинары. Содержимое не является личным, поэтому допустим дешёвый агрегатор — объёмы здесь обычно большие.

Шаги контура (нормализация, конспект, гейты качества, ревью-гейт) — в [`_shared/transcript-pipeline.md`](../_shared/transcript-pipeline.md). Здесь только специфика ветки.

## Когда эта ветка

Публичный материал: видео, рил, подкаст, эфир, лекция. **Личные записи сюда не отправлять** — для них ветка [`wiki-transcript-private`](../wiki-transcript-private/SKILL.md). Если по ссылке непонятно, личный это материал или публичный — спросить владельца; спросить некого — считать личным.

## Выбор провайдера

- Допустим мультитенантный агрегатор: дешёвая «turbo»-модель распознавания, точная модель — когда материал технический и важны имена/термины.
- Язык передавать **явно** (автоопределение ошибается на коротких и смешанных фрагментах).

## Как запускать

```bash
scripts/stt-public <ссылка|файл> <выходной.txt>
```

Скрипт вендор-нейтральный (любой провайдер с OpenAI-совместимым `POST /v1/audio/transcriptions`). Ссылку скачивает сам (`yt-dlp` + `ffmpeg`, 16 кГц моно). Без конфигурации падает с явной ошибкой.

## Конфигурация

| Переменная | Значение |
|---|---|
| `STT_PUBLIC_URL` | endpoint агрегатора (OpenAI-совместимый `/v1`) |
| `STT_PUBLIC_MODEL` | модель распознавания (дешёвая turbo или точная); обязательна — дефолтов в коде нет |
| `STT_PUBLIC_KEY` | ключ доступа |
| `STT_LANG` | язык явно (напр. `ru`) |

Значения — в переменных окружения или в файле `.env` в корне vault'а (в `.gitignore`; другой путь — `STT_ENV_FILE`). Формат: `KEY=value`, по строке. Шаблон — `.env.example` в корне репозитория. Устаревшие имена `STT_COMMON_*` ещё принимаются как алиас.

**Проверка перед сменой модели:** не всякая модель доступна у провайдера — при неверном имени сервис отвечает HTTP 404 с пустым телом, что выглядит как «ошибка транскрибации» без причины. Скрипт печатает код ответа явно: читать его до разбора результатов.

## Получение материала

1. **Аудио/видео по ссылке** — скачивание дорожки уже внутри `stt-public`, отдельный шаг не нужен.
2. **Готовые субтитры/транскрипт** — сначала попробовать штатный API площадки (YouTube и т.п.); если он доступен, распознавание вообще не требуется (дешевле и точнее). Фолбэк — извлечение звука и распознавание.
3. **Метаданные поста** (`yt-dlp --dump-single-json --skip-download <url>`) часто содержат описание и дату — они нужны для шапки `01-raw` и для сверки терминов.

## Гейты качества для публичных материалов

Материал публичный, но ошибки распознавания те же, поэтому перед записью фактов в вики:

- Имена продуктов, репозиториев, **версии** и авторство — сверить с первоисточником (`gh api repos/<owner>/<name>`, теги `gh api repos/<owner>/<name>/tags`, страница релиза, сайт). ASR регулярно путает или теряет компонент версии.
- Разделять роли: **спикер ≠ автор инструмента** — это частая ошибка, которую конспект потом транслирует как факт.
- Водяной знак распознавания или текст песни в результате = речи в дорожке нет; опираться на подпись/описание, а не на такой «транскрипт».
- Перед конспектом проверить, что термин вообще встречается в транскрипте (`scripts/verify_terms.py`), — иначе он попал из общих знаний.
