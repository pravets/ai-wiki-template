# Skills

Процедурные знания для ИИ-агентов, работающих с vault'ом этого шаблона.

## Формат

Каждый скилл — папка с `SKILL.md`: YAML-frontmatter (`name`, `description` — самодостаточный триггер) + тело с воркфлоу и чеклистами. Формат совместим с популярными агентскими платформами (Hermes Agent, Claude Code и др.).

| Скилл | Назначение |
|---|---|
| [wiki-init](wiki-init/SKILL.md) | первичная настройка vault'а: вопросы, схема, подрезка зон |
| [wiki-ingest](wiki-ingest/SKILL.md) | ингвест источника: inbox → raw → wiki → index/log |
| [wiki-verify](wiki-verify/SKILL.md) | проверка утверждений: источник → живая сверка → flags |
| [wiki-query](wiki-query/SKILL.md) | query-only исследование базы |
| [wiki-lint](wiki-lint/SKILL.md) | гигиена: сироты, противоречия, конфликты |
| [wiki-poi](wiki-poi/SKILL.md) | точки интереса: место → координаты → заметка + карта |
| [wiki-people](wiki-people/SKILL.md) | карточки людей: контракт frontmatter, диктовка, ревью-гейт |
| [wiki-transcript-common](wiki-transcript-common/SKILL.md) | транскрибация неприватного: видео, подкасты, эфиры |
| [wiki-transcript-private](wiki-transcript-private/SKILL.md) | транскрибация личного: голосовые, приватные встречи |
| [wiki-ocr](wiki-ocr/SKILL.md) | OCR: текст-слой → tesseract → облачный vision по согласию |

## Подключение к агенту

- **Hermes Agent**: симлинк в каталог скиллов — `ln -s <repo>/skills/<name> ~/.hermes/skills/<name>`; триггерится автоматически по `description`.
- **Claude Code**: аналогично — симлинк или копия в `.claude/skills/`.
- **Без поддержки скиллов**: дать агенту указание «перед операцией прочитай `skills/<name>/SKILL.md`» — см. секцию «Процедуры» в [`AGENTS.md`](../AGENTS.md).

> Скиллы транскрибации ссылаются на `skills/_shared/` (общий пайплайн и хелперы). Монтируйте её вместе с ветками — либо просто слинкуйте/скопируйте каталог `skills/` целиком. `_shared/` намеренно без `SKILL.md`, чтобы не регистрироваться как отдельный скилл.

> **Конфигурация движков — только через переменные окружения** (в коде и скриптах нет ни эндпоинтов, ни ключей). Приоритет: реальное окружение → локальный `.env` → дефолт. Шаблон переменных без значений — [`.env.example`](../.env.example) в корне; сам `.env` в `.gitignore`.

> **Хелперы** ([`_shared/scripts/`](_shared/scripts/)): `split_transcript.py` (разрез однострочного транскрипта), `verify_terms.py` (проверка термина по исходнику), `pdf_layer_check.py` (постраничный вердикт о текстовом слое PDF: `text-layer` / `needs-ocr` / `ambiguous` — нужен poppler, Python-зависимостей нет).

> **Самопроверка хелпера:** `python3 _shared/scripts/tests/self_test.py` — собирает фикстуры (цифровой PDF, скан, смешанный) и проверяет вердикты, точность слоя и мост «растеризация → tesseract». Требуется poppler; Pillow и tesseract необязательны (их отсутствие даёт пропуск, а не провал).

## Двухслойная модель

- Здесь — **generic-слой**: процедуры без личных данных, пригодные для публикации.
- **Личный слой** (конкретные пути, доступы, персональные грабли) держится локально у владельца как оверлей и ссылается на generic-скиллы, а не дублирует их.

Для контрибьюторов: примеры обезличивать, крупные изменения системы — через PR.
