# Wiki Courses: курсы, модули, инсайты

Зона `35-courses`: рабочий слой учёбы. Контракт зоны — [`35-courses/README.md`](../../35-courses/README.md); поля — `90-meta/templates/course.md`, `course-module.md`, `insight.md`.

## When to Use

- «Начал курс X», «запиши модуль», «зафиксируй инсайт», «что у меня к применению».
- Учебный материал: лекция, вебинар-курс, книга с заданиями, платный интенсив.

Не сюда: разовый доклад/вебинар без продолжения — это `10-wiki` (`type: talk`, скилл `wiki-ingest`).

## Ключевое различие

| Что | Куда | Признак |
|---|---|---|
| Курс целиком | `35-courses/<slug>/course.md` | есть программа и статус |
| Модуль/тема курса | `mNN-<тема>.md` | конспект без личного применения |
| Личный вывод | `insights/NN-<слаг>.md` | «я понял X → сделаю Y» в моём контексте |
| Переиспользуемое знание | `10-wiki/` | не зависит от курса, нужно через полгода без учебного контекста |

Инсайт без «Как применю» — не инсайт, а раздел модуля.

## Процедура 1: новый курс

1. Спросить: название, площадка, преподаватель, ссылка на курс, дата старта.
2. Слаг — kebab-case из названия (2–4 слова, латиницей): `stepik-upravlenie-komandoy`.
3. `mkdir -p 35-courses/<slug>/insights`, карточка по шаблону: `type: course`, `status: planned` или `active`, `started` (для `active` обязательна), `sources` — ссылку.
4. Теги — `learning` + доменный (`management`, `ai`, `1c`, `devops`…), только из таксономии `90-meta/schema.md`.
5. `make index` — курс появляется в хабе и индексе.

## Процедура 2: модуль

1. Источник: транскрипт в `01-raw/YYYY-MM-DD-<slug>-mNN-transcript.md` (скиллы `wiki-transcript-common` / `wiki-transcript-private`), ссылки на слайды — в `sources`. Бинарей в репозиторий не класть (правило 9 `AGENTS.md`).
2. Страница `mNN-<тема>.md` по скелету:
   - `## TL;DR` — 3–5 тезисов по одному предложению;
   - `## Ключевые знания` — по темам, с таймкодами и цифрами;
   - `## Что не понял / вопросы` — пустой лучше выдуманного ответа;
   - `## Что попробовать` — действия, из которых растут инсайты.
3. `part` — номер строкой (`"03"`, `"03a"` для добавленных задним числом).
4. Дописать строку модуля в «Программу» карточки курса.
5. Конспект — сжатие смысла, не пересказ лекции: то, что понадобится через полгода. Не длиннее 26 КБ — дольше, значит дели по темам.

## Процедура 3: инсайт

1. **Перед созданием — поиск похожих** (`wiki_search.py`, скилл `wiki-query`): похожий есть — дополнить, а не заводить второй.
2. Страница `insights/NN-<слаг>.md`: `type: insight`, `course`, `source` («[[m03-тема]] · 12:30»), `area` (`work`/`1c`/`personal`/`study`), `status: to-apply`, `sources`.
3. Тело: `## Суть` (2–4 предложения своими словами) → `## Как применю` (что, где, когда) → `## Проверка` (что должно измениться, когда вернуться).
4. Ссылка из модуля в «Что попробовать» или из карточки — чтобы не было сироты.

## Процедура 4: статусы

- `to-apply` → `applied` — применил; в теле дописать, что изменилось.
- `dropped` — не сработало; причина в теле, страницу не удалять.
- Всегда поднимать `updated`.

## Процедура 5: промоушен в 10-wiki

1. Признак: знание живёт без курса и пригодится вне его.
2. Предложить владельцу страницу `10-wiki/<slug>.md` (`type: concept` или `howto`), показать текст **до коммита** — ревью-гейт.
3. После «ок»: создать страницу, `sources` — модуль курса; у инсайта `status: promoted`, `promoted_to: [[10-wiki/<slug>]]`.
4. Обратная ссылка: в модуле или карточке — «промоутировано в [[10-wiki/<slug>]]».
5. Не копировать конспект целиком: в `10-wiki` идёт знание, очищенное от учебного контекста.

## Грабли

- **Не пересказ лекции.** Конспект, повторяющий ход занятия, бесполезен через месяц: нужны выжимка, цифры, таймкоды, грабли.
- **Модуль-заглушка не создаётся.** Просмотрел, но фиксировать нечего — страницы нет.
- **Бинари не класть** — слайды, PDF, видео только ссылками.
- **`hub.md` и секции курсов в `index.md` руками не правятся** — генерируются `gen_index.py`.
- **Теги только из таксономии**, максимум 5.
- **Промоушен без ревью-гейта запрещён**: знание в `10-wiki` претендует на проверенность.

## Чек-лист перед коммитом

- [ ] `course`/`part`/`area`/`status` заполнены и совпадают со слагом папки
- [ ] у инсайта есть все три раздела, «Как применю» — конкретное действие
- [ ] нет сирот: из модуля или карточки есть ссылка на каждый инсайт
- [ ] `make index` прогнан, `hub.md` собран
- [ ] запись в `log.md` в конец
