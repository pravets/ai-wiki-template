# Wiki Query: исследование без записи

Ответы на вопросы по содержимому vault'а. Операция read-only, но ограничения действуют и при чтении: маркеры зон и frontmatter `llm: ro` определяют, что можно использовать в ответе.

## Порядок

1. **Лексический поиск — BM25 первым, не grep.** `python3 90-meta/scripts/wiki_search.py "<запрос>" -n 8` (SQLite FTS5 + `bm25()`, русский стемминг): «индексы» находит «индекс», вес по колонкам (name ×5, tags/aliases ×3, headings ×2, kw ×2, body ×1), выдача с заголовком и выжимкой. Транскрипты — отдельным корпусом (`--raw`), иначе они забивают выдачу. Уже есть страница — `similar <slug>` покажет соседей по теме: дубль заводится только после этого. grep/ripgrep — вторая линия: точная строка, регулярка, имя файла, символ, которого нет в токенизаторе. Нет скрипта (чужой vault без `90-meta/scripts/`) — остаётся grep.
2. **Агрегаты** (количество точек по регионам, список тегов, выборки по frontmatter): скрипт на Python — обойти `.md`, распарсить YAML frontmatter, собрать словарь. Исключать `.git/` и `.obsidian/`.
3. **Смысловой поиск** (по теме, а не по слову): LLM-проход по выборке файлов или субагент с детальным брифом — grep не подходит.
4. **Подкрепление**: ответ ссылается на пути файлов и цитаты; ничего не домысливать. Нет данных в базе — так и сказать.

## Правила

- Читать можно всё; использовать в ответе — только то, что не закрыто маркером/`llm: ro` для агента.
- **Индекс — производный артефакт** (`.wiki-index/search.db`, в `.gitignore`), git-хук пересобирает его инкрементально на каждом коммите. Выдача выглядит подозрительно устаревшей — `make search` (или `wiki_search.py index`); с нуля — `make search-full`. Индекс не правится руками и не коммитится.
- **Стеммер — часть контракта поиска.** Нет `snowballstemmer` у того Python, что запускает скрипт — сборка индекса отказывается работать (иначе русская морфология молча ломается, и поиск находит только латиницу). Проверка: `wiki_search.py stats` печатает состояние стеммера.
- Некоторые инструменты чтения ложно определяют кириллические `.md` как бинарные — читать через Python с явной UTF-8.
- В рамках query-операции в vault не писать: `index.md` и `log.md` не трогать.
