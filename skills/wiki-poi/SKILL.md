# Wiki POI: место → заметка

Превращает упоминание места (пост, рил, статья, рекомендация) в заметку в `60-travel/poi/`. Зона rw, но действует ревью-гейт.

## Воркфлоу

1. **Определить место** по источнику: подпись, описание, геометка, текст.
2. **Проверить дубли**: поиск по `60-travel/poi/` и по `poi-map.md` — место могло быть добавлено раньше. Найденный дубль — не создавать, при необходимости обновить существующую заметку.
3. **Найти координаты** (лесенка ниже).
4. **Заполнить заметку** по шаблону `90-meta/templates/poi.md`: `name`, `region`, `type`, `status`, `coords`, `location`, `sources`.
5. **Показать владельцу** на согласование; коммит — только после его ОК.
6. **Коммит и учёт**: каждая POI — **отдельный коммит + push**; затем отдельным коммитом обновить хаб-страницу и `index.md`/`log.md`.

## Лесенка координат

1. 📍 из подписи/описания источника — часто там точные координаты.
2. Wikipedia API `prop=coordinates` по статье о месте (для объектов с вики-статьёй — самый надёжный путь).
3. **OSM Nominatim**, если вики-статьи нет: `https://nominatim.openstreetmap.org/search?q=<место>&format=json`. Для церквей искать не «Храм X», а каноническое название статьи — сначала поиск, потом координаты.
4. Только координаты поселения/урочища → **честная пометка**: `(ориентир села X, неточные)` + чекбокс «уточнить точное местоположение». Не выдавать ориентир за точную геоточку.

**Координаты не выдумывать.** Не нашлись — поля `coords`/`location` оставить пустыми, точку внести в таблицу без карты.

## Frontmatter и карта

- `coords: "lat, lng"` — человекочитаемо, для таблиц и выдачи.
- `location: "lat, lng"` — **обязательно для плагина Map View**: он читает только ключ `location` и игнорирует отдельные `lat`/`long`.
- `sources: []` — первоисточник обязателен (ссылка на пост/рил/страницу, зеркало если есть).
- `status`: `planned | visited | verified | unknown`. Если владелец упоминает, что уже был в месте — **спросить**, ставить ли `visited`; впечатления дописывать только по его диктовке.

## Хаб и группировка

- Хаб-страница `60-travel/poi-map.md`: POI сгруппированы по регионам с wikilinks + авто-таблица Dataview (`FROM "60-travel/poi" WHERE coords`) — обновляется сама по мере добавления точек.

## Грабли

- **Подборка мест в одном источнике** («N мест региона») — это N отдельных POI, каждое своим файлом и своим коммитом. Перед созданием каждого проверить базу на дубли.
- **Ссылка на источник** — не выдумывать: если место по подписи не определяется однозначно, спросить владельца (он знает свой контент), а не угадывать.
- Извлечение локации из соцсетей (метаданные поста, аудио, распознавание речи) — задача источника, а не этой заметки; сюда приходит уже установленное место. Если описания нет — запросить у владельца.
