# ai-wiki-template

Личная база знаний (`vault`) по паттерну **LLM Wiki** (raw → wiki → schema) с гибридным авторством: часть контента пишет человек, часть — ИИ-агент. Obsidian = IDE, агент = программист, vault = код.

Шаблон задаёт **структуру зон + систему прав (ACL-маркеры) + набор шаблонов** для безопасной совместной работы человека и агента в одном репозитории заметок.

## Что внутри

### Система прав (маркеры)

Пустой файл-маркер в корне папки определяет уровень доступа агента к зоне:

| Маркер | Значение |
|---|---|
| `.llm-ro` | read-only: читать можно, писать нельзя |
| `.llm-append` | append-only: добавлять новые записи, не редактировать/удалять существующее |
| `.llm-rw` | полный доступ |

**Нет маркера = read-only.** Корень vault — read-only. Frontmatter `llm: ro` на заметке перекрывает rw папки.

Подробный контракт и workflow — в [`AGENTS.md`](AGENTS.md).

### Зоны

| Папка | Права | Назначение |
|---|---|---|
| 00-inbox | rw | приёмная: клиппер, быстрые заметки |
| 01-raw | ro | исходники (текст), неизменяемые |
| 10-wiki | rw | знания: entity/concept-страницы, обзоры |
| 20-people | rw | люди: карточки + диктовка юзера |
| 25-interactions | append | взаимодействия |
| 30-journal | ro | ежедневные заметки |
| 40-projects | rw | проекты: README/status/log |
| 50-drafts | rw | статьи/посты/доклады (аккумуляторы) |
| 60-travel | rw | путешествия: trips/ (ro), poi/ (rw) |
| 90-meta | rw | шаблоны, аккумуляторы, служебное |

### Шаблоны (`90-meta/templates/`)

`person`, `interaction`, `project`, `talk-project`, `draft-ideas`, `poi`, `trip`, `wiki-concept`, `daily`.

### Скиллы (`skills/`)

Процедуры для ИИ-агентов: [wiki-ingest](skills/wiki-ingest/SKILL.md) (ингвест), [wiki-query](skills/wiki-query/SKILL.md) (исследование), [wiki-lint](skills/wiki-lint/SKILL.md) (гигиена). Формат и подключение — в [skills/README.md](skills/README.md).

## Развёртывание

1. **Клонировать**: `git clone <repo-url> ai-wiki` (или «Download ZIP»).
2. **Открыть** папку как vault в Obsidian.
3. **Установить плагины из каталога сообщества** (перечислены в `.obsidian/community-plugins.json`):
   - **Dataview** — таблицы по frontmatter (взаимодействия на карточках людей, poi-map)
   - **Obsidian Git** — автосинк/бэкап заметок
   - **Tasks** — задачи и сроки (📅⏫)
   - **Map View** — карта POI по ключу `location`
4. Ознакомиться с `AGENTS.md` и адаптировать зоны и правила под свои workflow.

## Правила для AGENTS.md

Работа агента в vault строится на «железных правилах»:
- Не выдумывать факты о реальном мире; записи по диктовке помечать.
- Каждый факт в `10-wiki` — со ссылкой на источник.
- Append-only для журналов; `30-journal` не редактировать.
- Даты ISO 8601, ссылки `[[wikilink]]`.

Полный список — в [`AGENTS.md`](AGENTS.md).

## Для контрибьюторов шаблона

Репозиторий хранит **только каркас** (структуру, маркеры, шаблоны, контракт) — без личного контента. Любые добавляемые примеры должны быть обезличены. Крупные изменения системы — через PR и обсуждение.
